PhD Researcher

Rafid Abyaad

How does a robot learn movements from a person, and build tasks from them?

Learning dynamic manipulation skills from human demonstration.

Rafid.Abyaad@bht-berlin.de · ORCID 0000-0002-8478-592X

Research focus

Rafid studies learning from demonstration for dynamic manipulation in tele.interaction. He uses TIAGo Pro to investigate how demonstrated skills can be adapted to new task requirements.

Robotic throwing serves as an experimental test task. The current work has been submitted to ICRA 2027 and is under review.

A longer-term direction is to organise learned skills into a reusable library and investigate how language models can select and combine them. Work on task composition is at an early stage.
